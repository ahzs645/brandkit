# UNBC source record

Retrieved 2026-10-26. The source of record is the [UNBC identity resource page](https://www.unbc.ca/communications-and-marketing/logos-and-graphic-standards) and its linked [February 2020 Graphics Standards Manual](https://www.unbc.ca/sites/default/files/sections/communications-and-marketing/unbc_gsm_feb2020.pdf).

The website SVG is original source artwork. Its path and polygon coordinates are preserved in the generated full logo; generated green is normalized from the website’s #00573D to the manual’s explicit #035642 recipe. EPS/GIF originals remain unchanged. The guide’s gold RGB 183,149,39 agrees with #B79527; the web table’s 183,149,3 is inconsistent.

The clear-space rule is official; the numeric ratio 16.05/434.89 is a conservative implementation measurement from this supplied artwork. Department/subdepartment font sizes, report margins and template layouts are local defaults. The university has not published a department-lockup sizing formula in this guide. Official departmental sub-logos must come from Communications and Marketing.

`PROVENANCE.json` records source URLs, retrieval date, archive members, hashes and transformations. `identity-rules.json` separates official guidance from implementation decisions. No logo lettering is retyped, isolated, rearranged or used to invent a new mark.
