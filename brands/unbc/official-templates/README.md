# Original UNBC templates

These files are the university-supplied originals linked from [UNBC branded templates](https://www.unbc.ca/communications-and-marketing/branded-templates), retrieved 2026-10-26. They are retained without edits. They are distinct from the local document applications generated by this kit.

- [Official UNBC letterhead](lhopt1official.docx) — [official source](https://www.unbc.ca/sites/default/files/sections/communications-and-marketing/lhopt1official.docx)
- [Official UNBC letterhead with address](lhopt3officialaddress.docx) — [official source](https://www.unbc.ca/sites/default/files/sections/communications-and-marketing/lhopt3officialaddress.docx)
- [Official UNBC green document cover](documentcoverunbcgreen.docx) — [official source](https://www.unbc.ca/sites/default/files/sections/communications-and-marketing/documentcoverunbcgreen.docx)
- [Official UNBC interactive document cover](documentcoverinteractive.docx) — [official source](https://www.unbc.ca/sites/default/files/sections/communications-and-marketing/documentcoverinteractive.docx)
- [Official UNBC PowerPoint template](unbcpowerpointtemplate.pptx) — [official source](https://www.unbc.ca/sites/default/files/sections/communications-and-marketing/unbcpowerpointtemplate.pptx)
