# Source references

- `logo-black.png`, `logo-white.png`, `mark-black.png`, `mark-white.png`, `wordmark-black.png`, `wordmark-white.png`: the logo files from First Form Brand Kit V1.0, as supplied. They are the only form the original logo exists in, and remain the reference for it.
- `logo-on-ash.png`: the logo upload from the same kit.
- `current-site.jpg`: the First Form website as it was when the kit was made.
- `PROVENANCE.json`: hashes of the supplied archive and of each file kept here, and how the vector logo was reconstructed from them.

The kit's HTML page and its two runtime scripts are not kept. Their content (palette, type, icons, rules, applications) is carried into `brand.json` and `docs/brand-details.html`.
