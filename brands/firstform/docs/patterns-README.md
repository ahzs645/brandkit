# First Form / Supporting pattern studies

First Form’s two-block mark becomes a system of assemblies, folds and construction lines. The original mark remains complete; the supporting planes and block studies use its 3:5 geometry in a restrained monochrome palette.

8 patterns, 2 editable applications, a PowerPoint layout and a separate pattern reference sheet. Open pattern-explorer.html offline to adjust scale, density and colour, and download SVG or PNG. patterns-guide.html explains applications.

These additions carry extension `pattern-explorations` in brand.json. The identifying artwork, original application layouts, historical guidance and approval records remain unchanged. Rebuild with the brand's existing generator, or npm run make:patterns.

- **Block weave**: The complete two-block mark alternates between upright and turned arrangements in a steady repeat.
- **Folded planes**: Small rhombi share the mark’s 3:5 slope. Three tones make a continuous field of folded material.
- **Mixed assemblies**: A single source block repeats at three sizes and four orientations inside a modular grid.
- **Assembly lines**: Stepped 3:5 construction lines cross the field, with a few complete blocks acting as anchors.
- **Form contours**: Nested outlines follow the block silhouette and expand beyond the frame. A focal graphic for a cover.
- **Staggered towers**: Larger source blocks alternate upright and inverted along staggered rows, like a collection of assembled parts.
- **Cut faces**: Two oversized blocks meet across a clear diagonal gap. Large crops turn the construction into an abstract composition.
- **Micro joints**: Tiny three-way junctions borrow the isometric angles. A quiet repeat for backs, dividers and margins.
