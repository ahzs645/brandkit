# Province of British Columbia: Visual Identity Program, 1977 (reconstruction)

**A historical reconstruction for reference and study. This is not the Province’s current
identity**, which the Government of British Columbia publishes.

The Visual Identity Program of 1977 set out the Province’s identity in four manuals: the General,
Reproduction, Sign and Vehicle manuals. They are rebuilt page by page in brandkit’s manual library
(`manuals/bc`). This kit is generated from `source/brand.json`, which turns their rules into data.

## What is here

- **Signatures**, composed on the Reproduction Manual’s cap-height grid (p. 12):
  - provincial
  - flush-left horizontal and vertical
  - stacked
  - centred and one line
  - the two sign formats
  - the vehicle-door format

  Each comes in every colourway. The departmental formats are also set for every ministry from
  1976 to 1986 (`logos/ministries/`), including the split ministries and branches the
  repro-sheet list names.
- **Stationery** for every rank, from the spec sheets on Reproduction Manual pp. 2–8:
  - Premier
  - Ministers
  - Deputy Ministers
  - Boards and Commissions
  - General Use
  - Special Use

  Each rank has a letterhead, envelope and calling card, with the manual’s design numbers in the
  descriptions.
- **Memorandum and news release** (General Manual p. 12).
- **Publications** (p. 8), **advertising** (p. 9) and **uniform insignia** (p. 13).
- **Vehicle markings**: door, box side, rear with striping (Vehicle Manual).
- **Signs**: primary and secondary identification, standard information, directional, warning,
  regulatory. They are laid out on the Sign Manual’s grid, where one square is 1/12 of the
  longest side.
- **A guide**, generated from the same definition.

## What is approximated

- **Typefaces.** Helvetica is set in TeX Gyre Heros, Courier in TeX Gyre Cursor. Both are
  open-licence equivalents (GUST Font License, `fonts/`), not the program’s own cuts. Helvetica
  Medium is Heros Bold. Ultra Light, used on the Premier’s stationery, has no open equivalent and
  is set in Regular.
- **Colour.** Pantone 462 is shown as a screen approximation (#5C462B). Proof any print against
  the ink.
- **The symbol.** It is the positive form only. The manual’s reverse form is separate artwork, in
  which the Union Jack stays black and the Sun white; it is not reconstructed. The reverse
  colourway draws the positive artwork in white.
- **Undimensioned items.** Where a manual prints no dimensions (publications, advertising,
  insignia), proportions are measured from its drawings. Each template’s description says so.
