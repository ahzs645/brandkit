# Changelog

## 1.1

Added Arrows, Signal, Connections and Layers: eighteen patterns, twelve editable applications, five guide pages and an offline comparison board. Twelve arrow and spark studies cover micro, staggered, oversized, mixed scales, inward rings, meeting points, eight-direction repeats, loose scatter, cross currents, arrows with sparks, orbit and spark constellations. An offline arrow explorer adjusts scale, density and colour and downloads vector SVGs. The original arrow is reusable as a named supporting symbol. Added Word lab notes and a project report, and the new covers to PowerPoint. Patterns and icons now appear for signature brands in the Logos tab.

## 1.0

Added SPARK Lab using its website SVG, theme colours, Outfit and Source Serif 4. Added stationery, lab materials, social and presentation templates, Word and PowerPoint exports, guide, details page, local website preview and motion library. Original artwork and source notes retained.
