# SPARK Lab brand kit

Original artwork from https://sparklab.unbc.ca/ with 30 editable templates, 15 guide pages, 16 motion studies, ten icons, 21 patterns, Office files and a local website preview.

- Open index.html to browse the complete kit.
- Logos: original, horizontal, stacked and wordmark; orange/navy, orange/cream, navy and white.
- Templates: stationery, project briefs, workshops, social, presentations, equipment and prototypes. Arrows, Signal, Connections and Layers add twelve applications and eighteen patterns. Compare them in docs/patterns-and-templates.html. Explore twelve arrow and spark patterns with mixed directions and scales in docs/arrow-patterns.html, with live scale, density and colour controls and SVG download. Replace bracketed fields with verified information.
- Documents: Word letterhead, project brief, Layers report and lab notes; six PowerPoint layouts; and an HTML email signature.
- Web: tokens, CSS, a typed React component, favicons, app icons and site/index.html.
- Motion: standalone library, tokens, rules and reusable CSS.
- Source: source/brand.json, reference artwork and font provenance. Rebuild with brandkit or npm run make:sparklab in the source repository.

The source artwork is preserved. Layouts, alternate arrangements, minimum sizes and motion are kit recommendations, not an approved UNBC manual. Colour recipes converted from screen values are estimates: proof before printing.
