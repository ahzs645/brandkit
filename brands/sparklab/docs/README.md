# SPARK Lab brand kit

Original artwork from https://sparklab.unbc.ca/ with 18 editable templates, 10 guide pages, 16 motion studies, ten icons, three patterns, Office files and a local website preview.

- Open index.html to browse the complete kit.
- Logos: original, horizontal, stacked and wordmark; orange/navy, orange/cream, navy and white.
- Templates: stationery, project briefs, workshops, social, presentations, equipment and prototypes. Replace bracketed fields with verified information.
- Documents: Word letterhead and brief, PowerPoint layouts and an HTML email signature.
- Web: tokens, CSS, a typed React component, favicons, app icons and site/index.html.
- Motion: standalone library, tokens, rules and reusable CSS.
- Source: source/brand.json, reference artwork and font provenance. Rebuild with brandkit or npm run make:sparklab in the source repository.

The source artwork is preserved. Layouts, alternate arrangements, minimum sizes and motion are kit recommendations, not an approved UNBC manual. Colour recipes converted from screen values are estimates: proof before printing.
