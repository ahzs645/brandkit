# Source references

- `six-dot-reference.png`: user-supplied current icon reference. Its six-dot arrangement and close relationship to the wordmark informed v2; v2.1 regularizes both horizontal and vertical dot gaps to the same value. Its font was not copied.
- `PROVENANCE.json`: input file hashes and the exact preservation policy.
- `legacy-v1/`: historical board, reconstruction proof, font comparison and original provenance. These show the former symbol and are retained as source history only.

All active v2 artwork uses the new six-dot symbol. Production lettering is the same vector geometry as in the supplied v1 archive.
