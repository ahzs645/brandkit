# ddcnorth site, redesigned (proposed v2.3)

The redesigned company website that the proposed v2.3 identity comes from, copied for reference
from the website repository (`ddcnorth/website`) at commit `4249136`, branch `redesign-minimal`.
That repository is the site's source; this copy is not written by any script and is not shipped
in the kit. `index.html` keeps its fonts embedded: Inter and Inter Display (SIL Open Font License
1.1) and Space Mono (SIL Open Font License 1.1), with their licences in `licenses/`.

`screenshots/desktop.jpg` (1440 px) and `screenshots/mobile.jpg` (390 px) are full-page captures
from that commit's acceptance tests (`docs/validation/screenshots/redesign-1440.jpg` and
`redesign-390.jpg`).
