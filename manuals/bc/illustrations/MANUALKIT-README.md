# ManualKit — trailer corrections and sign templates / R2

This release contains actual object edits relative to the last delivered UPDATED SVGs.
It is a targeted follow-up, not another full acceptance claim for the entire older library.

## Scope
- Ten trailer / tractor-trailer views inspected and refined: G16-tractor,
  V03-policy-tractor, V14-tractor-trailer, H46-tractor-trailer, the five V15 trailer
  views, and H46-flatbed.
- V12-truck-perspective corrected, including its eight visible rear-door reflectors.
- V17-compressor and H47-generator inspected as additional towable equipment;
  retained without a new mechanical contour change. They are not counted as new redraws.
- Forty new sign specimens: 9 General Manual G18; 20 Sign Manual (S03, S04, S05,
  S13, S15, S18, S20, S22, S24); 11 Hydro (H39, H40, H41).
- Counts refer to views/specimens, not distinct manufactured products. The sign
  package does not claim every repeated layout, dimension chart, construction or
  installation diagram in every manual. Ground, captions and unrelated overlapping
  illustrations are intentionally not part of the sign objects.

## Which file to open
VEHICLES: unbranded.svg is the normal identity-free export WITH source-visible
reflectors. geometry-only.svg / blank.svg omit optional applied markings.
markings-only.svg is provided for V12 and V15 rear. White door strips are reflective
appliques, not holes. The actual rear step/underframe apertures remain transparent.

SIGNS: example-editable-text.svg has editable text and replaceable symbols/identity.
example-outlined.svg / display.svg has stable outlined lettering. blank.svg contains
only the face and supports; face-only.svg omits posts. unbranded.svg retains example
words/symbols but removes example identity. branding-zones.svg has separate guides.
No fonts are included. Editable text uses Arimo/Arial and Tinos/Times fallbacks.

Extract a ZIP and open index.html. The viewer is self-contained and needs no network.
Browser controls were tested by supplying the local HTML directly to Chromium;
the test environment blocked file/loopback navigation. Relative evidence paths
were checked against the package files. See browser-qa.json for the test boundary.
Book-specific evidence packages contain unmasked source crops and fixed-coordinate
overlays. The SVG-only consolidated bundle omits these larger raster proofs.
The preview can toggle posts, applied markings and example sign graphics, or place
an uploaded SVG in a branding zone. Placement is a flat, unmirrored box fit, not a
projective four-corner warp. Use a vector editor for final perspective artwork.
The supplied proof overlay never purports to validate later branding modifications.

## Important findings
The previous perspective trailer side used the extended corner post as the whole
lower sill, producing a filled wedge over the undercarriage. The non-convex side,
underframe, tyre groups and coupling were reconstructed. V03 retains 23 source side
bands; V14 has 18 on each plane; General and Hydro panels stay plain.
V03 points left; G16 and V14 point right. Branding itself is never mirrored by this
viewer. V12 has eight visible rear strips (four per door); V15 rear has ten (five
per door). These specimen counts are not generic striping installation limits.

## Proof and limits
Original PDF filename, SHA-256, 1-based PDF page, SVG/PDF unit ratio, actual rounded
raster origin, current/previous SVG hashes and asset-specific notes are recorded.
The source is never masked by the reconstruction. No proof translation/rotation/
scale/warp was fitted to increase apparent agreement. Individual drawing elements
are deliberately edited at their recorded source landmarks.
These are clean illustrative reconstructions, not recovered production artwork,
engineering drawings, certified safety signs or an authenticated type/colour system.
Scan skew, ink spread, tiny hatching and pictogram curves are regularized. Hidden
support continuation and cropped geometry are not fully verified. Source example
identity reuses supplied project vectors, separately from the new object geometry.
The white/yellow/red Hydro control examples follow the accompanying historical
manual text even where the raster scan is gray. They are not current compliance advice.

The verification file checks file integrity, SVG structure, rendering and selected
transparent apertures. It does NOT turn these tests into a numerical fidelity score.
All original source PDFs and original project files are unchanged.
