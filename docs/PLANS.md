### Scope and decisions

- Work stays on branch `ddcnorth-v2.3`, cut from `main` at `93b7174`. Nothing is committed, pushed or merged without the user's approval; pushing `main` redeploys GitHub Pages (`.github/workflows/pages.yml`), and the shared ddcnorth link (`?brand=ddcnorth&share=1`) shows only the approved identity.
- The proposal is a revision: `{ id: "data-design-connection", title: "Data, design, connection", version: "2.3-data-design-connection", displayVersion: "2.3", status: "proposed", date: "2026-10-22" }` in `brands/ddcnorth/brand.json`, written by a new script `scripts/brands/ddcnorth-v23.mjs` (`npm run make:ddcnorth-v23`) that replaces its own entry and leaves everything else in the file as it was. The approved v2.1 and the 2.2 rising proposal are untouched; v2.3 is a sibling proposal over v2.1, not over 2.2.
- Revisions replace arrays whole. So that the proposal can add templates, patterns, icons and guide pages without copying the approved lists into it, the engine gains one merge operator: in a revision's `changes`, `{ "$append": [ … ] }` in place of an array appends to the array it patches. Existing patches behave exactly as before.
- New artwork follows the kit: colours by role or palette key only (or a palette colour with a two-digit alpha); headlines Inter Display at −0.04 em, labels Space Mono at +0.12 em; the logo and the complete six-dot symbol are never faded, animated or crowded (a complete symbol keeps one dot diameter clear); repeated or cropped symbols are motifs and are exempt from the clear-zone rule. Titles and notes use no em dashes (the house style the manual tests enforce).
- Motion is defined in the brand (`brand.motion`): tokens, rules and studies as data. The engine draws each study's final frame as SVG (no DOM, runs in Node) and writes motion files into the kit; the app animates the studies in a new **Motion** tab that appears only for a brand (or revision) that defines `motion`. Animation code lives in the app, not the engine.

```sh
npm ci

npx playwright install chromium
npm run test:browser
npm run build
node bin/brandkit.mjs check brands/ddcnorth/brand.json

```

`npm run test:browser` starts the Vite dev server on a free port, drives Chromium, writes `test/browser/report.json` (ignored by Git) and exits with code 1 if any check fails. `CHROMIUM_PATH` may point at an existing Chromium build.
